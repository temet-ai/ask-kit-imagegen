Maintain an evolving reference library for the user's interest or project.

1. List areas and choose the relevant one. Read its style, references and recent journal. Create
   an area if the user is establishing a new interest; explain the chosen name in the result.
2. Import actual image files with addReference. Preserve source/attribution, useful search tags,
   the reference's role and specific borrowing instructions. A URL alone is metadata, not image
   pixels; obtain an actual image through the caller's available tools before importing it.
3. Record explicit feedback with feedback, preserving the wording. Supply exactly one reference
   or job id. Narrow role/tags when the user endorses only a specific aspect. Approval means it
   can guide future automatic selection; candidate/rejected/archived references cannot.
4. Update setStyle only for general preferences the user actually gave. Merge new keep/avoid
   traits into existing lists unless replacement was requested. Keep uncertainty as a note.
5. Export sheet when a visual reference/style sheet is requested. Its HTML carries all guidance
   and feedback; PNG sheets show labelled thumbnails. No new image generation is needed.

Read operations work without act. Mutations need act and spend no image quota. Do not introduce
an approval question when the user's instruction already authorizes the relevant library change.
